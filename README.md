## Краткое описание
Изучение базовых команд Git: создание репозитория, коммиты,
ветки, слияния, разрешение конфликтов, работа с удаленным
репозиторием и .gitignore

## Использованные команды
git init — инициализация репозитория
git status — состояние рабочей директории
git add — добавление файлов в индекс
git commit — фиксация изменений
git log — история коммитов
git diff — разница между коммитами
git rm — удаление файла
git checkout -b — создание и переключение ветки
git merge — слияние веток
git remote add — привязка удаленного репозитория
git clone — клонирование
git push / git pull — отправка и получение изменений
